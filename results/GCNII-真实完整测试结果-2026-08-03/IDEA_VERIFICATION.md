# Candidate Under Review

**Candidate 1：注意力控制的深层 GCNII 邻居传播。**

候选保留 GCNII 的 initial residual connection（初始残差连接）与 identity mapping（恒等映射），并引入 attention mechanism（注意力机制）控制邻居传播。保留两项原始结构具有证据依据：作者将 GCNII 的深层有效性归因于二者共同作用，而非任一组件单独作用。[PE-7478DC0147，p. 8]

候选的可靠研究 Gap（研究空白）仅能表述为：**作者明确提出将 GCNII 与注意力机制结合，但具体结构、作用机制和效果尚未由现有证据确认。**[PE-7478DC0147，p. 8]

“注意力能够抑制导致表示趋同的邻居传播”属于待检验假设，不是论文已经支持的事实。

# Closest Prior Work

1. **GCNII** 是直接结构基础。其通过每层重新引入初始节点特征，并在权重变换中加入恒等映射，以支持深层传播。[PE-3F8784BD52，p. 2]
2. **GAT** 是当前证据中最接近“注意力控制邻居聚合”的已列方法，但现有材料只确认它被纳入全监督节点分类比较，没有提供其结构细节、深层行为或与 GCNII 组合的结论。[PE-7478DC0147，p. 8]
3. **APPNP** 同样利用初始表示回注保持局部信息，与 GCNII 存在结构目标上的接近关系；GCNII 还加入恒等映射并强调高阶多项式滤波器表达能力。[PE-3F8784BD52，p. 2]

当前只收录一篇论文，因此无法确认是否已有后续工作实现或系统研究“GCNII 与注意力结合”。最近前例及完整新颖性：**未确认**。

# Novelty Stress Test

最强反对意见是：**作者提出未来方向不等于该方向仍然新颖。**“将 GCNII 与注意力机制结合”可以证明问题来源可追踪，却不能证明尚无已有方法、也不能证明简单组合构成独立贡献。[PE-7478DC0147，p. 8]

候选若仅把常规注意力模块加入 GCNII，并报告准确率变化，其研究贡献不足以从当前证据中成立。更可辩护的范围应缩小为：检验选择性邻居传播是否对深层退化产生可区分的作用，而不是宣称提出新的深层 GNN 架构。

此外，GCNII 能表达任意系数高阶多项式滤波器的结论针对论文给出的原始模型。[PE-3F8784BD52，p. 2] 引入注意力后是否仍保留该理论解释：**未确认**，不得直接继承或宣称保持原理论性质。

# Feasibility Stress Test

该候选具有基本可操作性，因为 GCNII 已提供深度比较、组件消融和按节点度数分组的分析范式。[PE-7478DC0147，p. 8] 原论文还观察到网络加深时高阶节点准确率下降更快，且 64 层 GCN 无法正确分类度数大于 100 的节点。[PE-7478DC0147，p. 8]

但注意力控制的具体对象、计算方式及其与初始残差和恒等映射的接口均未确认。计算复杂度、内存开销、训练稳定性及重复实验条件也未确认。因此，目前只能确认研究问题可测试，不能确认工程成本或稳定训练的可行边界。

# Disconfirming Evidence

- GCNII 在不使用注意力的情况下，已经通过初始残差连接与恒等映射显著缓解深层过平滑；两者联合使用时，准确率可随网络深度增加而提升。[PE-7478DC0147，p. 8] 因此，注意力可能没有额外必要性。
- 注意力带来的结果改善可能来自额外容量、邻居重加权或优化差异，而非缓解过平滑。仅有最终准确率提升不能支持机制结论。
- 高阶节点退化证据来自对不同深度 GCN 的分组分析。[PE-7478DC0147，p. 8] 该现象能否直接迁移到 GCNII，或者能否由注意力缓解：**未确认**。
- 注意力也可能放大局部偏置、过度集中于少数邻居，或增加深层训练负担；现有证据未提供支持或反驳。

候选的核心假设可被否证：如果引入注意力后，深度增加时的退化趋势没有稳定减弱，或者改善不能与额外容量效应区分，则“注意力具有独立抗过平滑作用”的解释不成立。

# Unresolved Questions

1. 是否已经存在 GCNII 与 GAT 或其他注意力传播机制的直接组合：未确认。
2. 注意力应控制邻居选择、聚合权重还是其他传播环节：未确认。
3. 注意力是否改善高阶节点，还是仅改变总体预测性能：未确认。
4. 如何区分抗过平滑作用、普通容量增益与训练优化收益：未确认。
5. 修改后的模型是否仍具有 GCNII 的高阶多项式滤波器解释：未确认。
6. 该候选在归纳学习任务中的适用性，以及计算和内存成本：未确认。

该表述是可证伪的研究假设，不预设注意力必然有效，也不宣称修改后的模型继承 GCNII 的原始理论性质。
